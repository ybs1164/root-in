# Sticker generation preferences

When generating decoration stickers, do not generate Saturn or other planets, butterflies, mushrooms, umbrellas, rockets, standalone fruit of any kind (including peaches and lemons), horseshoes, crowns, or frogs unless the user explicitly requests that subject. This is a persistent user preference. Do not insert these subjects as secondary decorative motifs either. Fruit-containing foods such as cakes and drinks are allowed; the fruit restriction concerns standalone fruit stickers. These preferences govern future generation and do not remove existing app assets.

Preview-only sticker work must stay separate from app assets and code. Do not apply previews or create commits without user authorization.
