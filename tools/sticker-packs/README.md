# 스티커팩 편집기

개발 서버(`.claude/launch.json`의 `goodroot-dev`, 또는 `npm run dev`)를 띄운 뒤
http://localhost:5188/tools/sticker-packs/ 를 엽니다. 데스크톱 브라우저용입니다. 앱 빌드에는 들어가지 않습니다.

앱의 스티커 고르기(꾸미기 → 스티커)에 나오는 팩을 직접 만듭니다. 팩은 앱과 같은 CSS로 그려서 편집기에서 보이는 모양이 앱과 같습니다(크기 비율 그대로 — '폰 크기'가 실제 폰 폭).

- **팩 목록(왼쪽)**: 앱에서 `<` `>`로 넘기는 순서. + 새 팩 · 복제 · ↑↓ 순서 · 삭제.
- **팩(가운데)**: 스티커를 눌러 고르고 끌어서 옮깁니다. 고른 스티커는 아래에서 크기·회전·앞뒤 순서·복제·빼기. 방향키 = 옮기기(Shift는 크게), `[` `]` = 회전, `-` `=` = 크기, Delete = 빼기. **자동 정렬**은 격자로 다시 놓습니다. 흰 면 밖으로 나간 스티커는 빨간 테두리로 알려 줍니다(앱에서도 잘리지는 않음).
- **팩 꾸미기(오른쪽 위)**: 이름(띠에 적히는 글자, 16자), 읽는 이름(화면 읽기용), 띠 색 · 글자 색(색 고르기 또는 아래 조합), 이름 모양(기본 · 테두리 상자 · 굵게 기울임), 무늬.
- **스티커(오른쪽 아래)**: 앱 트레이의 스티커 전부. 팩 위로 끌어 놓거나 누르면 들어갑니다. 파란 숫자 = 그 스티커를 쓰는 팩 수. '안 쓴 것만'으로 아직 어느 팩에도 없는 스티커만 볼 수 있습니다 — **어느 팩에도 없는 스티커는 앱에서 고를 수 없습니다.**
- 되돌리기·다시 실행(Ctrl/⌘+Z, Shift+Ctrl/⌘+Z). 작업은 이 브라우저에 자동 저장되고, 다시 열면 이어서 합니다. **앱 값으로 되돌리기**는 앱에 들어 있는 팩으로 다시 시작합니다.

## 전달과 적용

1. 다 만들면 **내보내기** → `sticker-packs.json`이 내려받아집니다(다른 기기로 옮길 때는 **불러오기**).
2. 그 파일을 채팅에 올리고 적용을 요청합니다.
3. 적용(요청받았을 때만):

```sh
npx vite-node scripts/apply-sticker-packs.ts <sticker-packs.json>
```

앱이 읽는 방식(`readPacks`)으로 검사해 형식이 맞지 않는 팩·모르는 스티커 자리는 빼고 알려 주며, 쓸 수 있는 팩이 하나도 없으면 거부합니다. 이전 `src/domain/stickerPacks.json`은 `output/sticker-packs/backups/`에 보관합니다. 적용 뒤 `npm run check`.
