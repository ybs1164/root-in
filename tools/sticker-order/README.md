# 스티커 순서 정리

```sh
python3 tools/sticker-order/server.py
```

http://127.0.0.1:5178/ 에서 사용합니다. `src/domain/decor.ts`의 실제 `STICKERS` 순서를 매번 읽으며, 숨긴 스티커는 목록에서 제외합니다. 이미지는 앱의 `public/stickers`에서 그대로 불러옵니다.

- 손잡이 드래그: 마우스·터치 모두 지원하며 화면 가장자리에서 자동 스크롤합니다.
- 번호 입력 후 이동: 먼 위치로 바로 이동합니다. 손잡이에 포커스한 뒤 방향키로도 옮길 수 있습니다.
- 실행 취소·다시 실행·앱 순서로 되돌리기, 정렬 파일 내보내기·불러오기를 지원합니다.
- 각 카드의 체크를 해제하면 즉시 맨 아래 삭제 목록으로 이동합니다. 다시 체크하면 기존 위치로 복귀합니다. 삭제 선택도 실행 취소·다시 실행, 자동 저장, 파일 내보내기·불러오기를 지원합니다.
- 이동할 때마다 `output/sticker-order/order.json`에 자동 저장합니다. 저장 실패 시 브라우저 임시 저장과 파일 내보내기로 복구할 수 있습니다.
- 정렬이 끝나면 **정렬 완료 저장**을 누르고 채팅에 **정렬 완료**라고 알립니다. 이 단계까지는 앱 코드가 변경되지 않습니다.

## 저장한 순서 적용

사용자가 정렬을 마치고 적용을 요청했을 때만 실행합니다.

```sh
python3 tools/sticker-order/server.py --apply output/sticker-order/order.json
```

`completed: true`인 목록만 적용합니다. 화면의 번호가 아닌 안정적인 스티커 ID로 매칭하고, 누락·중복·모르는 ID와 작업 중 앱 목록 변경을 거부합니다. 선택한 순서를 활성 스티커에만 반영하고 숨긴 스티커 및 그 밖의 코드는 보존합니다. 적용 전 원본은 `output/sticker-order/backups/`에 보관합니다. 같은 순서를 재적용하면 파일을 변경하지 않습니다.

정렬 도중 앱 목록이 변경된 경우 기존 파일은 내보내기로 백업할 수 있습니다. 최신 앱 목록에서 새 정렬을 시작해 저장하면 이전 목록도 서버의 `backups/`에 보관됩니다.

## 검증

```sh
python3 -m unittest discover -s tools/sticker-order -p 'test_*.py' -v
```

표준 Python 라이브러리만 사용합니다. 도구는 로컬 주소에만 열리며, 웹 페이지에는 앱 적용 API가 없습니다.

저장 형식 v2의 `ids`는 삭제 예정 항목까지 포함한 전체 순서이며, `removedIds`는 삭제 예정 ID입니다. 이전 v1 파일은 삭제 선택 없이 불러옵니다. 적용 시 삭제 예정 ID를 앱의 숨김 목록에 추가하며, 기존 작업의 스티커 표시를 위해 원본 이미지와 ID 조회는 보존합니다.
