# 확대 지도와 주변 장소 표시

2026-10-28 수정. MapLibre와 카카오 지도에 공통 적용한다.

- 행정구역은 화면과 이동 여유 범위에 걸친 모든 시도·시군구를 조회한다. 중심의 몇 개 지역만 고르지 않는다. 하위 파일이 없으면 상위 구역을 유지한다. 도형을 재사용할 때도 빈 가장자리가 생기지 않도록 지형과 행정구역을 같은 범위로 조회한다.
- 지역명을 표시한다. 지형 위에 60m/px 이하에서 공원, 30m/px 이하에서 도로를 표시하며, 골목과 보행로는 기존 도로 등급별 확대 기준을 따른다. 멀리서는 간략한 지도를 유지한다.
- 주변 장소는 기준 위도 37.5도에서 12m/px 이하에 해당하는 줌부터 표시한다. `korea/places/<시군구>.json`의 기존 상가정보와 장소 종류별 아이콘을 사용한다. 별도 워커가 지도 좌표에 고정된 격자에서 대표 장소를 고른다. 격자는 줌 단계마다 반으로 나뉘며, 확대하면 기존 대표 장소를 유지하고 추가 장소를 표시한다. 이동·회전·기울기·화면 크기·패널·지역명·저장 핀으로 대표 장소를 다시 고르거나 숨기지 않는다. 화면 가장자리도 전체 격자와 여유 범위를 덮는 인접 시군구까지 조회해 같은 대표 장소를 유지한다. MapLibre는 화면 경계 대신 실제 카메라 줌으로 밀도를 정한다.
- 드래그 말풍선과 해당 위치에서 여는 핀 카드는 같은 격자의 가까운 장소를 사용한다(화면상 약 20px, 지리적으로 8~40m). 이름·종류·장소 ID·장소 좌표를 공유하며, 가까운 아이콘이 없을 때만 기존 카카오/Photon 주소 조회를 사용한다. 이전 드래그나 멀어진 좌표의 주소 응답을 현재 말풍선에 표시하지 않는다.
- 장소 아이콘을 누르면 해당 장소 카드가 열려 핀으로 저장할 수 있다. 축소하면 주변 아이콘을 숨기고, 이전 화면의 늦은 응답은 적용하지 않는다. 장소 파일 실패가 지형 표시를 막지 않는다.
- 상가정보와 별도로 기존 OSM 원본에서 대학·학교·역·병원·공공시설·공원·도서관·이름 있는 건물을 추출한 `public/map-landmarks/`를 함께 표시한다. 숭실대학교·숭실대입구역도 포함한다. 큰 시설은 40m/px, 동네 시설은 16m/px, 일반 건물은 4m/px 이하에서 표시한다. 시설용 격자를 상가와 분리해 상가 때문에 대학이 사라지지 않게 하고, 숫자만 있는 건물명은 제외한다. 시설 이름은 OSM의 한글 이름·띄어쓰기를 보존한다. 원본에 없는 시설이나 최신 변경 사항은 반영되지 않을 수 있다.
- 시설 데이터는 앱에 포함하며 원격 지형 데이터 주소와 분리한다. 0.25도 개요 타일과 0.1도 상세 타일 중 확대 단계에 맞는 타일만 받고, 인덱스·타일의 진행 중 요청과 결과를 재사용한다. 시설은 느린 상가 파일을 기다리지 않고 먼저 표시한다. 생성 스크립트와 라이선스는 `scripts/place-kinds/build_landmarks.py`, `public/map-landmarks/LICENSE.md`에 둔다.
- 첫 구역 도형은 지형 타일을 기다리지 않고 먼저 표시한다. 도형 재사용 범위 안의 이동은 지형 조회도 생략하고, 새 범위의 지형을 기다리는 동안 이전 지형을 유지한다. 동시에 같은 기본지도 인덱스·타일을 요청하면 다운로드를 공유한다. 한 화면의 취소가 다른 화면의 다운로드를 취소하지 않으며, 실패한 파일은 재시도한다.
- 현재 위치에는 이름표를 붙이고 시설·지역명 위에 표시한다. 위치 버튼은 새 좌표를 요청하며, 일시적인 위치 오류는 최근 위치를 최대 60초간 유지한다. 권한·위치 서비스가 꺼지면 즉시 지우고 백그라운드에서도 숨긴다.

회귀 검증은 `adminAreaService`, `areaRenderer`, `koreaMapService`, `baseShapes`, `mapStyle`, `kakaoCourseMap`, `nearbyPlaces`, `nearbyPlacesService`, `landmarkService` 테스트에서 범위·확대 단계·아이콘 간격·중복 요청·느린 응답·데이터 누락을 확인한다. `python -m unittest discover -s scripts/place-kinds`는 대학 관계 도형과 개별 건물 추출도 검사한다. UI 검증 이미지는 Git에 포함하지 않는 `ui-shots/`에 둔다.
