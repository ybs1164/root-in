# 확대 지도와 주변 장소 표시

2026-10-28 수정. MapLibre와 카카오 지도에 공통 적용한다.

- 행정구역은 화면과 이동 여유 범위에 걸친 모든 시도·시군구를 조회한다. 중심의 몇 개 지역만 고르지 않는다. 하위 파일이 없으면 상위 구역을 유지한다. 도형을 재사용할 때도 빈 가장자리가 생기지 않도록 지형과 행정구역을 같은 범위로 조회한다.
- 지역명을 표시한다. 지형 위에 60m/px 이하에서 공원, 30m/px 이하에서 도로를 표시하며, 골목과 보행로는 기존 도로 등급별 확대 기준을 따른다. 멀리서는 간략한 지도를 유지한다.
- 주변 장소는 12m/px 이하에서 표시한다. `korea/places/<시군구>.json`의 기존 상가정보와 장소 종류별 아이콘을 사용한다. 화면에 걸친 인접 시군구도 조회한다. 별도 워커가 데이터를 읽고 화면·가림 영역·회전을 반영해 아이콘 간격을 정한다. 저장한 핀과 지역명을 우선한다.
- 장소 아이콘을 누르면 해당 장소 카드가 열려 핀으로 저장할 수 있다. 축소하면 주변 아이콘을 숨기고, 이전 화면의 늦은 응답은 적용하지 않는다. 장소 파일 실패가 지형 표시를 막지 않는다.
- 원본 상가정보의 정규화된 이름을 사용하므로 띄어쓰기·지점명이 생략될 수 있다. 상가정보에 없는 공원·역 등 모든 시설의 아이콘을 보장하지 않는다. 공원 지형은 별도 기초지도 데이터로 표시한다.

회귀 검증은 `adminAreaService`, `areaRenderer`, `baseShapes`, `mapStyle`, `kakaoCourseMap`, `nearbyPlaces`, `nearbyPlacesService` 테스트에서 범위·확대 단계·아이콘 간격·데이터 누락을 확인한다. UI 검증 이미지는 Git에 포함하지 않는 `ui-shots/`에 둔다.
