# root-in UI 테마 시안

> 시안 이미지만 모은 곳이다. 앱 스타일(`src/styles.css`)에는 적용하지 않았다.

각 보드는 같은 세 화면(📍 핀 지도·핀 카드 / 🧭 경로 보기·폴더 창 / 📅 달력 TODAY·꾸미기)을 테마별로 다시 그린 것이라 나란히 비교할 수 있다. 지도는 실제 지도가 아닌 가짜 도시 블록 그림이다.

다시 만들기: `node docs/theme-concepts/src/build.mjs [테마id ...]` (Playwright 필요, 웹폰트는 `src/.fontcache`에 받아 둔다).

## 1. 레트로

70~90년대 인쇄물·전자제품 감성 — 베이지 배경, 두꺼운 테두리, 둥근 버튼, 살짝 바랜 색감. 오래된 잡지나 가전제품 조작부 같은 UI

![](01-retro.jpg)

## 2. Y2K

2000년대 초반의 디지털 미래주의 — 크롬 버튼, 반투명 패널, 별·하트·버블 장식. 옛날 MP3 프로그램이나 미니홈피를 미래적으로 만든 느낌

![](02-y2k.jpg)

## 3. 카세트

카세트테이프와 워크맨 중심의 아날로그 음악 감성 — 카세트 창, PLAY/STOP 버튼, 테이프 릴을 UI 요소로 활용. 물리 버튼을 누르는 듯한 인터페이스

![](03-cassette.jpg)

## 4. MP3 플레이어

2000년대 휴대용 디지털 음악기기 — 작은 LCD 화면, 원형 컨트롤러, 픽셀 폰트. 메뉴가 기기 내부 화면처럼 구성되는 UI

![](04-mp3.jpg)

## 5. 다이어리

개인 수첩을 꾸민 듯한 아날로그 감성 — 종이 배경 위에 포스트잇, 마스킹테이프, 스티커, 손글씨. 화면 자체가 한 페이지처럼 보이는 UI

![](05-diary.jpg)

## 6. 폴라로이드

즉석사진과 추억 기록 중심 — 콘텐츠가 폴라로이드 사진 카드로 표현됨. 날짜나 짧은 메모를 손글씨처럼 배치

![](06-polaroid.jpg)

## 7. 영화관

극장·티켓·상영관에서 가져온 디자인 — 영화표 모양 카드, 어두운 배경, 조명 효과. 버튼이나 탭이 티켓·상영시간표처럼 표현됨

![](07-cinema.jpg)

## 8. 영화필름

아날로그 필름과 영화 제작 감성 — 필름 스트립 형태의 리스트, 프레임 단위 이미지 배치. 스크롤하면 필름이 움직이는 듯한 구성

![](08-film.jpg)

## 9. 카페

따뜻하고 편안한 일상 공간 — 메뉴판 같은 카드, 둥근 버튼, 종이·우드 질감. 편안하고 정돈된 감성 앱 느낌

![](09-cafe.jpg)

## 10. 베이커리

빵집과 포장지의 따뜻한 분위기 — 빵 모양 아이콘, 체크 패턴, 둥글고 통통한 버튼. 메뉴판이나 빵 포장지 같은 UI

![](10-bakery.jpg)

## 11. 캔디

사탕처럼 알록달록하고 달콤한 디자인 — 젤리처럼 볼록한 버튼, 강한 라운딩, 반짝임. UI 요소마다 서로 다른 파스텔 컬러 사용

![](11-candy.jpg)

## 12. 초콜릿

달콤하지만 조금 더 차분하고 고급스러운 테마 — 초콜릿 조각 같은 사각 카드, 진한 브라운 배경. 패키지 디자인 같은 깔끔한 UI

![](12-chocolate.jpg)

## 13. 말차

차분한 일본식 녹색 디저트 감성 — 넓은 여백과 낮은 채도. 녹차 패키지·일본 카페 메뉴판처럼 차분하고 정갈한 UI

![](13-matcha.jpg)

## 14. 다이너 / 패스트푸드

미국식 레트로 식당과 패스트푸드점 — 체크무늬, 메뉴판, 주문번호표, 스티커형 버튼. 크고 명확한 버튼이 많은 활기찬 UI

![](14-diner.jpg)

## 15. 캠핑

자연·야외·캠핑 장비 감성 — 지도, 배지, 나무 표지판, 랜턴 아이콘. 카드가 캠핑 장비 태그처럼 보이는 UI

![](15-camping.jpg)

## 16. 여행

지도·항공권·여권·스탬프 중심 — 티켓 형태 카드, 여권 스탬프, 지도 선. 페이지 이동 자체가 여행 기록을 넘기는 느낌

![](16-travel.jpg)

## 17. 캘린더

일정표와 날짜 자체를 디자인 요소로 사용 — 날짜 블록이 핵심. 카드와 그리드 중심으로 매우 정돈된 UI. 날짜에 스티커나 아이콘을 붙이는 방식도 잘 맞음

![](17-calendar.jpg)

## 18. 귀여운 / Kawaii

캐릭터와 둥근 형태 중심의 귀여운 디자인 — 모든 모서리가 둥글고 아이콘도 캐릭터화. 버튼이 통통하고 표정·하트·별 같은 장식이 많음

![](18-kawaii.jpg)

## 19. 키치

일부러 촌스럽고 과하게 꾸민 재미 — 폰트·색·스티커를 의도적으로 뒤섞음. 정돈보다는 개성이 강하고 잡지 콜라주 같은 UI

![](19-kitsch.jpg)

## 20. 스티커

스티커 자체가 주요 UI 요소 — 버튼, 카테고리, 상태표시까지 스티커처럼 표현. 흰 테두리와 작은 그림이 화면 곳곳에 붙어 있음

![](20-sticker.jpg)

## 21. 장난감

플라스틱 완구와 어린 시절 놀이 감성 — 입체적인 플라스틱 버튼, 큰 아이콘, 강한 원색. 실제 장난감 기계를 조작하는 듯한 UI

![](21-toy.jpg)

## 22. 손그림

사람이 직접 그린 듯한 불규칙한 디자인 — 삐뚤어진 선, 손글씨, 직접 그린 아이콘. 버튼 테두리조차 완벽한 사각형이 아닌 UI

![](22-handdrawn.jpg)

## 23. 낙서

노트 위에 자유롭게 끄적인 디자인 — 공책 배경, 볼펜 선, 형광펜, 화살표와 메모. 정보 주변에 의미 없는 낙서까지 배치 가능

![](23-doodle.jpg)

## 24. 동화책

그림책의 삽화와 페이지 구성 — 페이지를 넘기는 듯한 화면 전환, 삽화 중심 카드. UI 자체가 책 속 그림의 일부처럼 자연스럽게 섞임

![](24-storybook.jpg)

## 25. 꿈

흐릿하고 현실과 동떨어진 몽환적 분위기 — 블러, 빛 번짐, 반투명 카드, 느린 애니메이션. 버튼이 떠다니거나 구름처럼 배치되는 부드러운 UI

![](25-dream.jpg)

## 26. 드림코어

어린 시절의 익숙한 이미지와 비현실적 공간을 결합 — 구름·들판·별·창문·옛 컴퓨터 그래픽 등을 혼합. 익숙하지만 묘하게 이상한 UI. 메뉴가 공간 속에 떠 있는 듯한 구성

![](26-dreamcore.jpg)
