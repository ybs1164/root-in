# 지도 장소(건물·스티커) 우선순위

2026-11-04. 지도 위 장소 아이콘(OSM 시설 + 상가정보 가게)을 한 화면에 무엇을 보일지 정하는 규칙.

## 규칙 (지금 동작)
- **한 화면에 한 종류는 하나만** — 같은 `kind`(= 같은 스티커)는 화면에 두 번 나오지 않는다. 건물(`building`)도 한 종류.
- 화면 = 실제 보이는 영역(돌린 지도면 돌린 화면, `inScene`). 화면 밖 여유 범위의 장소는 그리지 않는다(옮기는 동안 가장자리는 손을 뗄 때 채워짐).
- **스티커·라벨은 조금도 겹치지 않는다**(2026-11-09, 옛 격자 한 칸에 하나 규칙을 바꿈): 점수가 높은 순으로 넣되, 스티커나 이름이 이미 넣은 장소의 스티커·이름과 1px이라도 닿으면 뺀다(`declutter`, `src/domain/poiScene.ts`). 동점은 장소 id 해시.
  - 상자는 마커 CSS(`.map-nearby-place`)를 그대로 따라 화면 px로 계산: 스티커는 **실제로 보이는 윤곽**(알파 128 이상, 크기 맞춤 배율 적용 뒤 — `src/domain/poiStickerBounds.ts`, `python scripts/poi-sticker-bounds.py`로 다시 만듦; 스티커를 바꾸거나 `poiStickerScale.ts`를 고치면 다시 돌릴 것), 이름은 글자 수로 어림(한글 1em·그 밖 0.6em·띄어쓰기 0.3em, 상가 10px·최대 70px, 시설 11px·최대 110px). 돌린 지도는 화면 축으로 돌려서 잼(`screenPoint`) — 마커는 똑바로 서 있으니까.
  - 배율로 키운 그림이 48px 칸 아래로 나가면 이름을 그만큼 내림(`stickerBelow` → `--poi-art-below`): 스티커가 자기 이름을 가리지 않게.
  - **지도에 보이는 내 핀은 언제나 이김**: 핀 마커(38px) 자리에 닿는 장소 스티커·이름은 빼고, 핀이 새로 생기면 그 자리 장소는 바로 사라짐(`useNearbyPlaces`의 `pins`).
- **안정성**: 옮기거나 확대할 때는 지금 화면에 있는 장소가 화면에 남아 있는 한 그대로(`keep`) — 더 나은 같은 종류가 새로 들어와도 바꾸지 않는다. 축소하면 새로 고른다. 내 기록이 바뀌어도 보이는 것은 그대로, 다음 축소 때 반영.
- 줌 단계(m/px, 위도 37.5° 기준)는 그대로: 40 이하 큰 시설(대학·역·공항·병원), 16 이하 동네 시설, 12 이하 가게, 4 이하 일반 건물. 단 OSM 유명도 70 이상인 동네 시설(궁궐·유명 박물관)은 40부터(`PROMOTE_FAME`).

## 점수
`s = 0.6·F + 0.2·종류 선호 + 0.2·(가 본 곳이면 1)` (`placeScore`)

- **F 유명도 (데이터만으로)**
  - 시설: 등급 바닥값 0.45 / 0.3 / 0.15 + 0.55 × OSM 유명도/100 (`landmarkFame`). OSM 유명도(0~100)는 `scripts/place-kinds/build_landmarks.py` `fame`: wikidata·wikipedia 50, heritage·historic 20, 관광 명소·박물관·미술관·전망대 10, 20층·80m 이상 10, 면적(1천 m² → 0, 100만 m² → 20). 타일 행 8번째 칸 `{areaM2, f}`(없으면 0 — 옛 타일도 열림). 같은 곳의 점·면이 겹치면 큰 값을 합침.
  - 가게: 상가정보엔 유명도가 없어서 불러온 시군구 안 같은 이름 수로 브랜드 인지도를 대신함, 최대 0.3 (`shopCandidates`). '업소명없음'은 아예 빼고 한 글자 이름은 브랜드로 안 셈. 한계: '펜션'·'힐링' 같은 흔한 이름도 브랜드처럼 셈.
- **내 기록 (이 기기에서만 계산, 서버·분석으로 안 보냄)** `buildPlaceProfile`: 핀 3 · TODAY 핑 2 · 루트 정류장 2, 반감기 45일. 종류 선호는 `w / (최대 + 2)`라 핀 하나로 한 종류가 모든 칸을 이기지 않음. 가 본 곳 = 그 기록 자리 40m 안 + 이름이 같거나 한쪽이 다른 쪽을 포함(최근 600곳). 제외 주소 핑(`local`)은 안 씀.
